
1. การเตรียมและแปลงข้อมูล (Data Ingestion & Preprocessing)
--------------------------------------------------------------------------------
- โหลดข้อมูลจากไฟล์ penguins_lter.csv ด้วย pandas
- คัดเลือก Features ทางกายภาพ 4 ตัวแปร ได้แก่:
    * Culmen Length (mm) - ความยาวสันจะงอยปาก
    * Culmen Depth (mm)  - ความหนาจะงอยปาก
    * Flipper Length (mm) - ความยาวครีบปีก
    * Body Mass (g)       - น้ำหนักตัว
- กำหนด Target เป็น Species (สายพันธุ์ของเพนกวิน)
- ใช้ .dropna() ตัดแถวที่มีค่าว่าง (NaN) ทิ้งทั้งหมด
- แยกตัวแปรต้น X ให้เป็น Matrix ตัวเลขขนาด (N, 4) และตัวแปรตาม y เป็นเวกเตอร์ขนาด (N,)
- แปลง Label (ชื่อสายพันธุ์) จากข้อความให้เป็นตัวเลข 0, 1, 2 ด้วย LabelEncoder


2. การแบ่งชุดข้อมูลและการปรับสเกล (Splitting & Scaling)
--------------------------------------------------------------------------------
- ใช้ train_test_split แบ่งข้อมูลออกเป็น:
    * Training Set: 80%
    * Test Set: 20%
    * random_state=42: กำหนด Seed ให้การสุ่มคงที่ทุกครั้งที่รัน
    * stratify=y_encoded: ล็อกสัดส่วนของแต่ละสายพันธุ์ใน Train และ Test ให้เท่ากันตามสัดส่วนจริง
- ใช้ StandardScaler ปรับสเกลข้อมูลตัวแปรต้น X ให้เป็น Z-score (Mean = 0, Std = 1)
  เพื่อไม่ให้ค่าน้ำหนักตัว (หลักพัน) บดบังค่าความลึกจะงอยปาก (หลักสิบ)
- ปรับสเกลด้วย fit_transform บน Train Set และ transform บน Test Set เพื่อป้องกัน Data Leakage


3. สถาปัตยกรรมโครงข่ายประสาทเทียม (Neural Network Architecture)
--------------------------------------------------------------------------------
สร้างโมเดลแบบ Sequential (ไหลไปข้างหน้าทีละชั้น) ประกอบด้วย:

[Input: 4 Features]
        |
        v
[Dense Layer 1: 16 Nodes] 
- คูณเวกเตอร์ Input กับ Matrix น้ำหนักขนาด (4, 16) + Bias
- ผ่าน Activation Function: ReLU (f(x) = max(0, x)) เพื่อดึงความสัมพันธ์ที่ไม่เป็นเชิงเส้น (Non-linear)
        |
        v
[Dense Layer 2: 8 Nodes]
- สกัดและลดมิติข้อมูลลงเหลือเวกเตอร์ขนาด 8 Nodes
- ผ่าน Activation Function: ReLU
        |
        v
[Output Layer: 3 Nodes]
- คำนวณผลรวมเชิงเส้นออกมาเป็น Logits 3 ค่าแทน 3 สายพันธุ์
- ผ่าน Activation Function: Softmax เพื่อแปลงค่าให้อยู่ในรูปความน่าจะเป็น (Probability) รวมกันได้ 1.0


4. การกำหนดค่าและการเทรนโมเดล (Compile & Training Loop)
--------------------------------------------------------------------------------
- Optimizer: Adam (Learning Rate = 0.01) เป็นตัวปรับค่าน้ำหนัก (Weights & Biases) อัตโนมัติ
- Loss Function: sparse_categorical_crossentropy ใช้คำนวณข้อผิดพลาดสำหรับโจทย์ Multi-class 
  ที่ Label เป็นตัวเลขจำนวนเต็ม (0, 1, 2)
- Metrics: วัดความแม่นยำด้วย accuracy
- กระบวนการเทรน (model.fit):
    * epochs = 50: วนลูปเรียนรู้ข้อมูลครบทั้งชุดจำนวน 50 รอบ
    * batch_size = 16: ส่งข้อมูลเข้าไปคำนวณ Gradient และปรับ Weights ทีละ 16 ตัวอย่าง
    * validation_split = 0.1: หักข้อมูล 10% จาก Train Set มาเป็นชุดตรวจเช็ก (Validation) ประจำรอบ


5. การประเมินผลและการแสดงกราฟ (Evaluation & Visualization)
--------------------------------------------------------------------------------
- นำโมเดลที่เทรนเสร็จแล้วไปวัดผลกับ X_test_scaled เพื่อดูค่า Test Loss และ Test Accuracy
- นำค่าบันทึกประวัติ (history) มาพล็อตด้วย matplotlib ออกเป็น 2 กราฟ:
    1. กราฟ Accuracy (Train vs Val): ติดตามอัตราความแม่นยำที่เพิ่มขึ้นในแต่ละ Epoch
    2. กราฟ Loss (Train vs Val): ติดตามค่าความผิดพลาดที่ลดลงในแต่ละ Epoch
- ใช้เส้น Train เทียบกับ Val เพื่อตรวจสอบภาวะ Overfitting (โมเดลเริ่มจำข้อสอบเก่าแต่ทำนายข้อมูลใหม่ได้แย่ลง)
